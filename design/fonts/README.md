# Geist font files

The UI lab bundles the variable webfont builds from Vercel's official Geist v1.7.2 release:

- `Geist-Variable.woff2` is Geist Sans for the design editor.
- `GeistMono-Variable.woff2` is Geist Mono for the terminal surface.
- `OFL.txt` is the upstream SIL Open Font License 1.1.

Source: <https://github.com/vercel/geist-font/releases/tag/v1.7.2>
